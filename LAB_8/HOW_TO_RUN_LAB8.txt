================================================================================
 LAB 8: MOBILE ROBOT NAVIGATION USING ROS & GAZEBO — QUICK EXECUTION GUIDE
 Ubuntu 24.04 + ROS 2 Jazzy + Gazebo Sim 8 (Harmonic)
================================================================================

All files are located in: ~/GAZEBO/LAB_8

Open THREE terminals. In EVERY terminal, first run:
  source /opt/ros/jazzy/setup.bash
  cd ~/GAZEBO/LAB_8
  export LIBGL_ALWAYS_SOFTWARE=1

--------------------------------------------------------------------------------
 PROBLEM 1: Battery-Aware Autonomous Robot Agent
--------------------------------------------------------------------------------
Terminal 1 (Gazebo):
  gz sim -r problem1_battery_aware_robot_world.sdf

Terminal 2 (Bridge):
  ros2 run ros_gz_bridge parameter_bridge --ros-args -p config_file:=problem1_battery_aware_robot_bridge.yaml

Terminal 3 (Navigation Node):
  python3 problem1_battery_aware_robot_node.py

  * What you see: Robot visits tasks, monitors battery drain, detects low battery,
    aborts task, returns to dock, recharges to 95%, and resumes unfinished task!

--------------------------------------------------------------------------------
 PROBLEM 2: Decentralized Multi-Robot Exploration
--------------------------------------------------------------------------------
Terminal 1 (Gazebo):
  gz sim -r problem2_decentralized_exploration_world.sdf

Terminal 2 (Bridge):
  ros2 run ros_gz_bridge parameter_bridge --ros-args -p config_file:=problem2_decentralized_exploration_bridge.yaml

Terminal 3 (All 3 Decentralized Agents):
  python3 problem2_decentralized_exploration_node.py --robot all

  * What you see: 3 robots explore independent rooms, share frontiers over P2P
    broadcast, prevent redundant visits, and handle comms dropouts gracefully.

--------------------------------------------------------------------------------
 PROBLEM 3: Distributed Multi-Robot Mission Planning & Fault Recovery

Terminal 2 (Bridge):

Terminal 3 (Fleet Agents):
  python3 problem3_distributed_mission_planning_node.py --robot all

Terminal 4 (Optional - Test Fault Recovery):
  ros2 topic pub /fleet/inject_failure std_msgs/msg/String "{data: 'robot3'}" --once

  * What you see: 4 robots bid on depot tasks via auction, navigate using A*,
    and automatically reassign tasks if robot3 fails!
