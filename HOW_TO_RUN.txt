Task 3, 5, 6 — Ubuntu 24.04 + ROS 2 Jazzy + Gazebo Sim 8 (Harmonic)
=====================================================================
Your VM has Gazebo Sim 8.10 (ROS Jazzy). That is the correct simulator.
There is no "Gazebo 18" package. Do not install Gazebo Classic 11.

Open THREE terminals. In EVERY terminal run:

  source /opt/ros/jazzy/setup.bash
  cd ~/GAZEBO

If the LiDAR cloud is missing or Gazebo is black, also run this in the Gazebo terminal:

  export LIBGL_ALWAYS_SOFTWARE=1


------------------------------------------------

------------------------------------------------
task 1: gz sim -r hospital_corridor.sdf

 gz sim -r warehouse_path.sdf

did not use -r.


------------------------------------------------
Terminal 2 — ROS <-> Gazebo bridge (same for 3, 5, 6)
------------------------------------------------
  ros2 run ros_gz_bridge parameter_bridge --ros-args -p config_file:=$HOME/GAZEBO/ros_gz_bridge.yaml

Leave this running. Check with:

  ros2 topic list
  ros2 topic echo /robot/scan --once
  ros2 topic echo /robot/odometry --once

You must see LaserScan ranges (not a silent wait). If /robot/scan never prints,
the Python node cannot avoid walls.

------------------------------------------------
If something fails
------------------------------------------------
1. "Waiting for odom + LiDAR"
   Bridge not running, or you started Python before Gazebo finished loading.
   Wait 5 seconds after Gazebo opens, restart the Python node.

2. Robot does not move
   ros2 topic echo /robot/cmd_vel
   If that prints but the robot is still: Gazebo is paused (press play).

3. LiDAR is empty in VirtualBox
   Close Gazebo, then:
     export LIBGL_ALWAYS_SOFTWARE=1
     gz sim -r <world>.sdf
   Worlds already use render_engine ogre (required on VirtualBox).

4. Wrong Gazebo
   Use:  gz sim -v 8 -r shopping_mall.sdf
   ROS Jazzy is built against Gazebo Sim 8, not gz-sim10.
